Axians — Modular C++ IoT Framework

Reusable C++ IoT architecture designed to reduce repeated project setup and make future sensor integrations faster.

RESUMERESUME EXPERIENCE
01 / CONTEXT

Reusable architecture in an IoT engineering environment

Recurring project work required common sensor, connectivity, data acquisition, and persistence infrastructure to be recreated repeatedly.

02 / PROBLEM

Repeated setup consumed engineering time

The goal was to establish reusable C++ building blocks that could be composed into future IoT projects instead of recreating common infrastructure.

03 / MY OWNERSHIP

Architecture, implementation, and communication

Designed and developed reusable components for sensor integration, sensor data acquisition, connection to the wider software stack, and storing sensor information in a DevOps database.

04 / ENGINEERING DECISIONS

Modular reusable components instead of project-specific setup

The framework separated common concerns into reusable components so new sensor projects could focus more quickly on the project-specific layer.
